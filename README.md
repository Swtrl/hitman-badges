# hitman-badges
An app dedicated for creating all bages available in Hitman WOA between levels 1 to 12500. 
How to use:
1. Double-click START_HITMAN_BADGES_V2.bat
2. When asked for the export folder path, paste the full path to the extracted JPEXS export folder.
   Example:
   C:\Users\YourName\Desktop\hitman_export
3. When asked for levels, enter for example:
   1337
   or
   1337,2251
   or
   1-100
   or
   all
4. Press Enter.
5. The generated final badges will appear in a new folder called 'output_badges'.
