# hitman-badges
An app dedicated for creating all bages available in Hitman WOA between levels 1 to 12500. 
How to use:
1. Double-click START_HITMAN_BADGES_PNG_EDGE.bat.
2. Enter the path to the extracted assets folder when asked.
Example:
Q:\Games\Hit\2

3. Enter the level(s) you want to generate.
Examples:
1337
1337,2251
1-100
all

4. Finished PNG files will be created in:
output_badges_png
